# 我的大学 · 985 / 211 / 专业

一个纯静态的「大学 + 专业故事」网页。39 所 985、76 所 211、45 个通用专业已上线；首页支持搜索和地区筛选，点卡片直接全屏播放，自动开启语音和轻快 BGM。

## 直接打开

双击 `index.html` 即可（本地文件模式）。  
如果浏览器对本地音频有限制，在项目目录运行：

```bash
python serve.py
```

然后打开 `http://127.0.0.1:8017/`。同一 Wi-Fi 下手机也可以访问（终端会提示局域网地址）。

## 交互

- 点击首页卡片：直接全屏播放，自动开启语音 + BGM，不弹任何窗。
- 左右滑动 / 方向键 / 底部箭头翻页。
- 语音播完自动进入下一张；第 4 张播完停在最后一张，BGM 停止，不弹结尾卡。
- 播放键暂停/继续，喇叭键静音；左上角 × 关闭播放器。
- 直接打开 `school.html?id=xxx` 时，浏览器允许则自动播放；被浏览器拦截时点一下播放键即可。
- 桌面端是手机框；移动端全屏。

## 修改 / 增加学校

- **标准版**：改 `build/rebuild_schools.py` 的 `rows`，以及 `build/data_985_stats.py` 的保研率/A+ 数据，然后：

```bash
python build/rebuild_schools.py
python build/render_covers.py <id>
python build/tts_all.py
```

- **深度版**：直接改 `data/schools.js` 里的对象，再渲染该 id 并重新生成 TTS。
- 重新生成全部 39 所四图：`python build/render_covers.py`（默认会渲染 39 个 id，耗时较长）。

## 替换音频 / BGM

- 语音：把你的 MP3 直接覆盖 `audio/<id>/01.mp3` … `04.mp3` 即可，播放器不需要改。
- BGM：覆盖 `assets/music/bgm.wav` 即可（建议 30–60 秒、可循环、音量不要太大）。
- 重新生成 TTS：`python build/tts_all.py`（默认 `zh-CN-XiaoxiaoNeural`，语速 +4%，音高 +2Hz；已有文件会跳过）。

## 数据口径

- 深度版 5 所：学科评估为教育部第四轮（2017），A+ 数量：清华 21、北大 21（并列全国第一）、浙大 11、复旦 5、上交 5；软科 2026 中国排名：清华 1、北大 2、浙大 3、上交 4、复旦 5；深造/就业为 2025 届公开报告或权威转述。
- 标准版 33 所（不含大工样板）：2026 届保研率第三方统计、A+ / 强势专业、6 个王牌专业、就业方向。
- 大工全国版样板：2026 届保研率 24.3%（主校区约 32%）、7 个 A 类学科、6 个王牌专业、就业去向；不含分省分数。
- 所有政策与专业设置，最终以学校本科招生网及各省考试院公布为准。

34 所标准版统一用校名徽章；清华、北大、复旦使用官方校徽，上交、浙大用校名徽章占位。替换校徽时改对应数据里的 `emblem` 即可。

本页为个人整理的非官方页面，校徽版权归各校所有；音频为 TTS 合成，BGM 为本地合成，未使用商业音乐。
